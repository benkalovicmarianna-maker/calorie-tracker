# NutriTrack — Трекер харчування та калорій

Веб-застосунок для відстеження калорій, макронутрієнтів та водного балансу.

## 📋 Опис MVP

NutriTrack — це зручний харчовий щоденник, який допомагає контролювати раціон харчування. Застосунок дозволяє вести облік спожитих калорій по прийомах їжі, відстежувати баланс білків, жирів і вуглеводів та контролювати водний баланс протягом дня.

## ✨ Функціонал

- 🔍 **Пошук їжі** — база з 44+ продуктів з повним складом КБЖУ
- ✏️ **Своя їжа** — додавання власних страв вручну
- 📊 **Графіки** — статистика по калоріях та нутрієнтах за 7 днів
- 🎯 **Денна ціль** — встановлення індивідуальних цілей (4 пресети)
- 🍽️ **Прийоми їжі** — сніданок, обід, вечеря, перекус
- 💧 **Water tracker** — відстеження споживання води
- 💾 **LocalStorage** — дані зберігаються в браузері

## 🛠️ Технологічний стек

- **React 18** + **Vite 5**
- **Recharts** — графіки та візуалізація даних
- **Lucide React** — іконки
- **LocalStorage** — збереження даних

## 🚀 Запуск проєкту

```bash
# Встановлення залежностей
npm install

# Запуск у режимі розробки
npm run dev

# Збірка для продакшену
npm run build

# Попередній перегляд збірки
npm run preview
```

Після запуску відкрий [http://localhost:5174](http://localhost:5174)
